# YouTube Hands-On Tutorials

Source code and notebooks from my YouTube channel — every video has a matching file you can run yourself.

## Contents

| File / Folder | What It Covers |
|---|---|
| `gpt_image_1_DHS.ipynb` | Hands-on with GPT-Image-1: generating images with OpenAI's image model |
| `GPT-Image-1_Sticker_Generator` | Build an AI sticker generator using GPT-Image-1 |
| `kimi_k2_hands_on.py` | Exploring Kimi K2 — Moonshot AI's frontier model |
| `langGraph.py` | Building stateful AI agents with LangGraph |
| `financial-analyst/` | Multi-agent financial analyst built with CrewAI + MCP |
| `n8n-Content-Creator-Agent.json` | n8n workflow: autonomous content creator agent |
| `Marketing Poster Automation.json` | n8n workflow: AI-powered marketing poster generator |

## How to Use

1. Clone the repo:
   ```bash
   git clone https://github.com/sjsoumil/Youtube-Hands-on-Tutorials.git
   ```

2. Open the notebook or script for the tutorial you want to follow.

3. Each file is self-contained — install any dependencies mentioned at the top of the file.
